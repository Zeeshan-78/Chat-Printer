Export a WhatsApp chat with media

Updated 18 November 2026 · 5 minute read

A chat without its photos, voice notes and videos loses a lot. WhatsApp can include them in the export, but you get a zip file full of loose files. This guide explains what is inside and how to keep everything together.

What the zip file contains

The export has one text file with the messages and one file for every photo, voice note, video, sticker or document. Each message points to its file by name, for example IMG-20261112-WA0001.jpg.

Why export size matters

Media makes the export large and WhatsApp may keep only the most recent messages when you include media. If your chat is long, export it in parts, or export without media for the older years.

Voice notes and the .opus format

WhatsApp saves voice notes as .opus files. Chrome and Firefox play them. Some older Safari versions cannot, so open the finished file in Chrome if a voice note stays silent.

Keep everything in one file

Chat Printer reads the zip in your browser and shows photos, plays voice notes and plays videos inside the chat view. The Download HTML option saves a single file that contains the messages and the media, so you can open it on any device without the zip. Photos also appear in the PDF and PNG exports; audio and video are replaced by a label there, because a PDF cannot play them.

Media is included with a paid export (pay once per chat). The Free plan converts the text only.

Tips

  • Keep the original zip as a backup.
  • Use a date range to make the HTML file smaller.
  • Large chats need a computer; phones may run out of memory with a very large zip.
